How it works

  1. Connect GitHub once. The saved connection does not expire when you log out of CYBER HOST.
  2. Select any accessible repository from the complete paginated list.
  3. Enter BOT_TOKEN and any other environment variables required by the project.
  4. Import. User deployments wait for admin approval; admin deployments launch immediately.

This imports a snapshot of the selected branch, not automatic push-to-deploy. Only deploy source code you trust.
